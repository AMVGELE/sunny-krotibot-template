# Sunny

Sunny is a personal assistant for KrotiBot. Give Sunny a question to research, two options to compare, or rough notes to turn into a draft. Sunny replies in the language you use.

## Add Sunny to KrotiBot

In KrotiBot, choose **+ → Import…** and paste this repository’s address. [Template repository](https://github.com/AMVGELE/sunny-krotibot-template)

You can also download `bot.md`, attach it in a KrotiBot conversation, and ask “Create a personal assistant named Sunny from this template.” [Open bot.md](./bot.md)
